# 3D-визуализатор генератора

Из корня `synconv` включи просмотрщик в обычную сборку:

```sh
cmake -S src -B build -DENABLE_GENERATOR_VIEWER=ON
cmake --build build
```

Для этой опции нужны Qt 5.15, Qt Quick Controls 2, Qt Data Visualization и Qt Concurrent. Если CMake не находит Qt, укажи путь к установке через `CMAKE_PREFIX_PATH`. По умолчанию опция выключена.

На macOS запусти `open build/libs/generator/misc/generator_viewer.app`. При одноконфигурационной сборке на Linux запускаемый файл — `build/libs/generator/misc/generator_viewer`.

Кнопка `+` добавляет пик, а `−` удаляет выбранный. Выбери пик в списке, чтобы изменить его форму, координаты, амплитуду или ширину. На поверхности видна сумма всех пиков и общего шума. При пустом списке можно посмотреть один шум.

Для нормального шума задаются среднее и СКО. При нулевом СКО каждый отсчёт получает постоянную добавку, равную среднему. Для равномерного шума задаются минимум и максимум, а среднее находится посередине этого интервала. Шум прибавляется к пикам до взятия модуля.

Шаги H и V задаются независимо. Во время перетаскивания ползунка график обновляется в режиме предпросмотра. На мелкой сетке в этом режиме узкий пик может попасть между отсчётами, а реализация шума может отличаться. При отпускании строится поверхность на выбранных шагах с заданным seed.

Для вращения веди двумя пальцами по тачпаду над графиком или перетаскивай мышью с зажатой правой кнопкой. Для масштаба используй щипок на тачпаде Mac или колесо мыши.

Высота и цвет показывают значение свёртки от 0 до 100. Для плотных сеток поверхность показывает максимумы блоков в их центрах. Полярные строки и обе стороны шва 0°/360° сохраняются отдельно. Под графиком указаны размер исходной сетки, её максимум и размер отображаемой поверхности.
